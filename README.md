# BetterTasks

A replacement Google Tasks panel for Google Calendar.

Google Tasks's native side-panel view sucks. Subtasks don't render indented
(or have any real visual indicator that they're a subtask), making that feature
useless. You can't tag or categorize tasks within a list (so you must create
a list for each category, which means you can only ever see one category of 
tasks at a time). The integration and seamlessness between Google Tasks and 
Google Calendar is amazing, but the actual organizational power of Google Tasks
is very very limited. 

Other task management platforms also suck. They force you to install new apps 
on your phone, have terrible mobile interfaces (e.g. Notion), or require you to 
fill out a bunch of information manually since it can't parse natural text (which
is one of my favorite GCal features). 

This app aims to solve all of that. Not only does it resolve everything named 
above, but it retains seamless integration with Google Tasks and Google Calendar,
so you don't enter new app installation hell. It also enables powerful features 
such as adding how long a task might take, auto-scheduling work time for tasks, 
autodetecting category colors and category names from your GCal, and a host of 
other productivity features. It parses a lot of that metadata from your existing 
workflow so you don't need to learn a whole new syntax or deal with filling out 
1000 text fields. 

Essentially, entering "writ440 readings tmrw 9pm 30m" on your phone's Google Tasks
app creates a new task called "[WRIT 440] Readings", categorized under WRIT 440, 
made due tomorrow at 9pm, and the app suggests 30 minute blocks for you to work 
on it.  

Nothing ever leaves your account: all of this is done by storing information
within your Google Tasks and Calendar. This just makes those two apps better.
